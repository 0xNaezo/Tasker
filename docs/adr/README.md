## Формат

Файл называется `NNNN-short-slug.md`: `NNNN` — следующий свободный номер, дальше — короткое название латиницей. Разделы:

- **Статус** — «Принято» и дата, или «Заменено ADR NNNN».
- **Контекст** — какая задача стоит и какие есть ограничения.
- **Решение** — что сделано и где это видно в коде.
- **Последствия** — что из этого следует, включая минусы.
- **Альтернативы** — что рассматривали и почему отказались. Раздел пишут, если альтернативы были.

Принятый ADR не переписывают. Если решение меняется, пишут новый ADR, а у старого меняют статус на «Заменено ADR NNNN».

На номера ADR ссылается код: ADR 0001 — в `app/build.gradle.kts` и `baselineprofile/.../AppJourneys.kt`, ADR 0004 — в `CrashReporting.kt`. Номера не меняют.
