# 0006. Доступ к ИИ зависит от канала установки

## Статус

Принято, 2026-10-06. Провайдер и модель заменены [ADR 0011](0011-openrouter-provider.md): вместо Claude API и Anthropic Java SDK — OpenRouter и модуль `core:ai-openrouter`, ключ пользователя — ключ OpenRouter. Остальное в силе.

## Контекст

- ИИ ускоряет работу, но не нужен для неё: ежедневная автоматика работает на правилах ([план, §17.1](../tech-plan.md#171-принципы)).
- Ключей провайдера в APK быть не должно ([план, §21](../tech-plan.md#21-безопасность-и-приватность)).
- До публикации в Google Play сервер не нужен. APK из GitHub не проходят проверку Play Integrity, поэтому доступ к прокси для них нечем защитить ([план, §17.2](../tech-plan.md#172-устройство)).
- Провайдер — Claude API ([план, §17.4](../tech-plan.md#174-модель-и-параметры-api)).

## Решение

Режим доступа задаёт канал сборки — флейвор измерения `channel` ([`app/build.gradle.kts`](../../app/build.gradle.kts), [`AppModule.kt`](../../app/src/main/kotlin/app/tasker/di/AppModule.kt)):

| Канал | Откуда ставится | Режим ИИ | Кто платит |
| --- | --- | --- | --- |
| `github` | Android Studio, GitHub Releases | напрямую: запросы идут с телефона в Claude API со своим ключом пользователя | пользователь, через свой ключ |
| `play` | Google Play | через прокси `backend`: токен установки выдаётся после проверки Play Integrity | владелец прокси |

**Прямой режим.**

- Пользователь вводит свой ключ API Anthropic в настройках.
- Ключ хранится зашифрованным: Tink AEAD (AES-256-GCM), набор ключей обёрнут мастер-ключом Android Keystore (`ApiKeyStore`, `SecretVault`).
- Файлы секретов лежат в `noBackupFilesDir/ai_secrets`, поэтому в Auto Backup не попадают.
- Запросы выполняет официальный Anthropic Java SDK (модуль `core:ai-claude`).

**Режим прокси.**

- Адрес прокси задаёт свойство Gradle `tasker.aiProxyUrl`. Без него сборка `play` ИИ не предлагает. Релизный workflow берёт адрес и номер облачного проекта из переменных GitHub Actions `TASKER_PLAY_PROXY_URL` и `TASKER_PLAY_CLOUD_PROJECT` (`.github/workflows/release.yml`).
- Токен Play Integrity запрашивается через классический API (`IntegrityTokens.kt`). Номер облачного проекта задаёт свойство `tasker.playCloudProject`.
- `ProxyAiGateway` получает токен установки и запрашивает новый после ответа 401. Он соблюдает `Retry-After`, а после окончательного отказа в установке час не обращается к Play Integrity.
- Вместо Play Integrity debug-сборка может отправить ключ dev-окружения прокси в заголовке `X-Dev-Install-Key` (свойство `tasker.aiProxyDevKey`). Свойство читается только для типа сборки `debug`, в релиз ключ не попадает.

**Общее для обоих режимов.**

- Промпты, схемы ответов и их проверка лежат в `core:ai-contract`. Прямой режим и backend выполняют одни и те же маршруты. Приложение пока вызывает один маршрут — enrich (`AiGateway.enrich`).
- Модель по умолчанию — `claude-opus-5-5` (`AiSettings.DEFAULT_MODEL`). Глубина рассуждений (`effort`) задаётся явно для каждого маршрута (`AiRoute`).
- **ИИ выключен до согласия.** `AiSettings.isActive = enabled && hasConsent`. `AiGatewayProvider` отдаёт `DisabledAiGateway`, пока выключен переключатель, нет согласия, выбранный режим недоступен в этой сборке или, в прямом режиме, не сохранён ключ.
- **Выключение.** Переключатель отменяет очередь, в том числе текущий запуск. Уже заполненные поля остаются с пометкой ИИ (`AiController`).
- **Правила работают без ИИ.** Парсер ([ADR 0003](0003-rule-based-input-parser.md)) и догоняющая обработка (`MaintenanceRunner`, правила R1–R5) ИИ не вызывают.

## Последствия

- В сборке `github` без ключа ИИ недоступен. В сборке `play` без `tasker.aiProxyUrl` — тоже.
- Режим, выбранный в сборке другого канала, считается невыбранным (`AiGatewayProvider.effectiveMode`). После перехода из GitHub в Google Play режим выбирают заново.
- Ключ API не попадает в резервные копии. После переустановки или переноса на новый телефон его вводят снова.
- Расходы прямого режима идут на ключ пользователя. Расходы прокси ограничены лимитами backend: по умолчанию 200 запросов на установку в день и $20 общего бюджета в день ([`backend/README.md`](../../backend/README.md)).
- Play Integrity проверен только на локальном фейке `decodeIntegrityToken`, не на серверах Google ([`backend/README.md`](../../backend/README.md), «Known limitations»).

## Альтернативы

- **Прокси для всех сборок.** Отвергнут: APK из GitHub не проходят Play Integrity, и доступ к прокси нечем защитить.
- **Ключ провайдера внутри APK.** Запрещён планом ([§21](../tech-plan.md#21-безопасность-и-приватность)).
- **Модель на устройстве.** Отложена ([план, §2](../tech-plan.md#2-решения-по-открытым-вопросам), решение 2). Интерфейс `AiGateway` позволяет добавить её позже.
